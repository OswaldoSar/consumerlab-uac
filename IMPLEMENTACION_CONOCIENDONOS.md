# Implementación de “Conociéndonos” y fotocheck estudiantil

## 1. Nombre sugerido del formulario

**Conociéndonos: perfil y avatar del estudiante – Psicología del Consumidor y Marketing**

## 2. Separar información pública y privada

### Datos autorizados para el fotocheck
- Nombres y apellidos.
- Nombre que desea mostrar.
- Código universitario, solo si la institución lo requiere.
- Carrera o grupo.
- Fortaleza o “superpoder”.
- Frase breve.
- Código de avatar.
- Autorización para mostrar esos datos en la tarjeta.

### Respuestas solo para el docente
- Expectativas del curso.
- Forma preferida de aprender.
- Preocupación académica.
- Algo poco conocido que se sienta cómodo compartiendo.
- Apoyo que espera recibir del docente.

Las preguntas personales deben ser opcionales. No solicitar diagnósticos, información íntima, creencias, orientación sexual, situación económica, dirección u otros datos sensibles.

## 3. Avatares

La página contiene ocho avatares originales, identificados con los códigos A01–A08. En Google Forms, cree una pregunta de opción múltiple con esos códigos y, si lo desea, agregue una imagen para cada alternativa.

## 4. Flujo recomendado

1. El estudiante explora los avatares en la página.
2. Completa Google Forms y selecciona el código.
3. Las respuestas pasan a Google Sheets.
4. Se usa una plantilla en Google Slides para el fotocheck.
5. Apps Script reemplaza nombre, frase, fortaleza y avatar, y genera los archivos.
6. En la siguiente clase se entrega el fotocheck y se realiza una dinámica de presentación.

## 5. Configuración del formulario

- Recopilar correos verificados.
- Limitar a una respuesta.
- Desactivar edición posterior.
- No mostrar el resumen de respuestas.
- Incluir una autorización explícita para los datos que aparecerán en el fotocheck.
